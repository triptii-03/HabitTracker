Habit Tracker

A full-stack Habit Tracker application built using React and Node.js. 
The application allows users to add habits, mark them as completed, and delete habits.

Features

- Add new habits
- Assign a category to each habit
- Mark habits as completed
- Delete habits
- Fetch and display habits using a REST API
- Responsive and user-friendly interface

Technologies Used

Frontend
- React.js
- JavaScript
- JSX
- HTML
- CSS
- Bootstrap
- Vite

Backend
- Node.js
- Express.js
- REST API
- CORS
